# Localization Docs

本目录放多语言、首页内容本地化、字幕语言和远程语言包相关文档。

## 文档

- [Localization And Home Data Architecture](localization-and-home-data-architecture.md)：多语言固定包、内容本地化、首页数据和字幕的规划。

- UI 文案本地化、内容语言、字幕选择和远程语言包统一放在本目录。
- API header 的 `Lang`、runtime locale fallback 仍以 `docs/api/` 和 `docs/runtime/` 为准，本目录只描述产品和内容层语义。
